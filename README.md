# API REST - Gestión de Artículos

API REST desarrollada con **FastAPI** para la gestión de artículos. Permite crear, consultar, actualizar y administrar artículos mediante endpoints HTTP y modelos de validación con **Pydantic**.

## Tecnologías

- Python
- FastAPI
- Pydantic
- Uvicorn

## Funcionalidades

- Crear artículos
- Consultar artículos
- Consultar un artículo por ID
- Actualizar artículos
- Validar datos mediante Pydantic
